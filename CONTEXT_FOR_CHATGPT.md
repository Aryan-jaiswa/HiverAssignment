## 1. Project Overview & Problem Statement
This project is an AI agent designed to automate Twitter customer support for the `AppleSupport` handle. It was built for a Hiver Take-Home Assignment. 

The primary challenge it solves is **balancing the Automation Rate with Safety**. Large Language Models (LLMs) often hallucinate refund policies or provide dangerous technical advice when confused. This project solves that problem by wrapping the LLM in a rigid, deterministic **Escalation Engine** and grounding its generation using Retrieval-Augmented Generation (RAG) backed by a FAISS index of historical support data.

## 2. Core Architecture & Workflow
The system is built as a pipeline (`src/pipeline.py`) that processes incoming customer messages in the following order:

1. **Intent Classification (`src/intent/classifier.py`)**: 
   - Uses a Sentence-Transformers (`all-MiniLM-L6-v2`) centroid-based classifier to predict the user's intent and assign a confidence score.
2. **Pre-Generation Escalation Checks (`src/escalation/engine.py`)**:
   - If the intent confidence is too low (e.g., `< 0.65`), it immediately escalates to a human agent, preventing the LLM from ever seeing it.
3. **Historical Evidence Retrieval (`src/retrieval/api.py` & `index.py`)**:
   - Queries a local FAISS index (exact inner-product search) to retrieve the top similar historical customer interactions to serve as ground truth for the LLM.
4. **Secondary Escalation Check**:
   - If the retrieved FAISS evidence has a similarity score below a safe threshold (e.g., `< 0.70`), it escalates to a human agent.
5. **LLM Generation (`src/generation/generator.py` & `provider.py`)**:
   - Uses Gemini 1.5 Pro to generate a response. The prompt includes the customer message and the retrieved historical evidence to prevent hallucination.
6. **Post-Generation Validation**:
   - The LLM's output is parsed as JSON (containing `needs_escalation`, `reply`, and `reason`). If the LLM self-reports confusion or lacks context, it falls back to escalating to a human.
7. **Final Output**:
   - Either an automated `reply` to the customer or a decision to `ESCALATE`.

## 3. Technology Stack
- **Language**: Python 3.10+
- **Machine Learning**: `sentence-transformers`, `faiss-cpu`, `scikit-learn`, `pandas`.
- **LLM Integration**: `google-genai` (Gemini 1.5 Pro).
- **Web/API**: `fastapi`, `uvicorn`, `streamlit` (UI).
- **Testing & Tooling**: `pytest`.

## 4. Codebase Structure
- `config/`: Contains `config.yaml` (paths, thresholds) and `intent_schema.yaml` (taxonomy of intents).
- `data/`: Contains `raw/twcs.csv` (Kaggle dataset) and processed datasets.
- `src/`: Core logic.
  - `src/api.py`: FastAPI server exposing the `/api/v1/support` endpoint.
  - `src/ui.py`: Streamlit frontend for interacting with the agent.
  - `src/pipeline.py`: The `SupportAgent` orchestrator class that ties all components together.
  - `src/intent/`, `src/retrieval/`, `src/escalation/`, `src/generation/`: Modules for the respective pipeline steps.
- `scripts/`: Execution scripts for building datasets, indexing FAISS, and running the evaluation suite.
- `tests/`: Pytest test suite covering all modules.
- `docs/`: Markdown documents like `misleading_numbers.md` detailing engineering decisions.
- `PRODUCTION_READINESS.md`: An audit of known edge cases and architectural bugs to fix (e.g., swallowed exceptions, hardcoded paths).

## 5. Current State & Known Issues
The core ML pipeline is fully functional and achieves its goal of safe automation. However, there are known production-readiness bugs documented in `PRODUCTION_READINESS.md`:
1. **Silent LLM Failures**: If the Gemini API fails, the `provider.py` catches the exception and returns an empty dictionary `{}`, which crashes `pipeline.py` with a `KeyError`.
2. **Missing Input Validation**: The JSON generated by the LLM is not strictly validated with Pydantic models before being parsed by the pipeline.
3. **Hardcoded Configurations**: Some paths in `config.yaml` are relative and break if the API is run from a different directory.
4. **Test Setup**: `pytest` requires `PYTHONPATH="."` to run properly because the `src` directory isn't installed as a package via `setup.py` or `pyproject.toml`.
